- audience fit
- boundary compliance
- CTA clarity
- mobile behavior
- implementation readiness

## Handoff To Implementation

Before UI implementation starts:

- tie the work to a story
- lock the chosen direction here or in the repo's equivalent canonical design brief
- note any rejected directions when that context matters
- confirm the implementation surface being built

## Verification

- rendered review
- responsive review
- consistency review against planning docs
